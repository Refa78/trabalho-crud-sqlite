# Sistema de Cadastro de Alunos 

## Descrição
Este projeto é um sistema CRUD desenvolvido em Python utilizando SQLite e interface de texto.

## Funcionalidades
- Cadastrar alunos
- Listar alunos
- Buscar alunos por ID
- Atualizar alunos
- Deletar alunos

## Tecnologias utilizadas
- Python
- SQLite

## Como executar

Abra o terminal na pasta do projeto e execute:

```bash
python main.py
